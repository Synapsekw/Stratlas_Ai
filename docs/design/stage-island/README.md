# Stage island prototype

Throwaway prototype for the stage island (the in-app status surface). It is a visual reference only, not production code.

- Open `index.html` directly in a browser. No build step or server is needed; fonts load from `fonts/`.
- The Demo chip lists the states to walk through.
- `stage.jpg` and `clip.jpg` are the reference images used by the prototype.
