Quadrion AI is a desktop application by Synapse Solutions ("we"). This policy explains what happens to data when you use it.

## Offline first

Quadrion AI works on your computer. Your projects, photos, video, 3D models, point clouds, maps, annotations and reports stay on the drives and network shares where you keep them. Quadrion AI makes no network requests by default and needs no account.

## No telemetry

Quadrion AI does not collect usage statistics, analytics, crash reports or personal data, and has no advertising. Diagnostic logs and crash reports are written only to your own computer; they leave it only if you choose to send them to us yourself.

## When Quadrion AI connects to the internet

Only after an action of yours, and only to the service named:

- **Cloud AI, with your own API key.** Cloud AI is off by default. If you turn it on and add an API key from Anthropic, OpenAI or Google, the text and images you choose to send in an AI conversation go directly from your computer to that provider, under that provider's terms and privacy policy. Quadrion AI shows what will be sent before the first message in a project. Synapse Solutions does not receive or store this content, and projects shared as read-only packages can forbid cloud AI altogether.
- **Map downloads.** When you add a map region, Quadrion AI downloads map data from the map data server shown in Settings. The request contains the area you asked for, not your project data.
- **Update check.** Off by default. If you turn it on, Quadrion AI asks the update address you set whether a newer version exists. Copies from the Microsoft Store are updated by the Store.

An administrator can turn all of these off for a workstation.

## API keys

API keys you enter are stored in your operating system's credential store (Windows Credential Manager, or the macOS Keychain), never in project files, logs or settings files, and are sent only to the provider they belong to.

## Children

Quadrion AI is a professional tool and is not directed at children.
