# Engineering components without drawings

The engineering model workflow must discover separate equipment from a metric point cloud when no drawing is supplied. Original photos remain supporting evidence. The existing drawing-assisted route and source coordinate frame must remain intact. A separately frozen model is comparison evidence only; it must never seed discovery.

The initial implementation targets the supported telecom monopole family. It reuses the pure face/box detector from the telecom detection work through a narrow adapter, rather than copying that feature's UI or pipeline. This does not establish support for arbitrary asset families.

The adapter reads cloud points, the fitted axis and radius profile. It selects a bounded equipment region, deterministically samples it, detects faces and independent oriented boxes, and returns existing component observations with stable IDs. It uses no drawing inventory, prior model, hard-coded device count, site coordinate or reference dimensions. It preserves project-local metre coordinates. Missing backs, uncertain device types, unsupported orientation and rejected candidates must remain disclosed.

Long panel candidates and small enclosures remain separate selectable objects. An enclosure whose radio classification is not supported remains an equipment box. The assembler must not duplicate these with its coarse fallback devices. Geometry provenance distinguishes measured dimensions from inferred thickness/centre. Existing cloud fitting continues to supply the shaft, compound roofs, climbing hardware and other supported parts.

The first fresh local run exposed a missing dependency: device discovery alone does not supply the mounting pipes and platforms that the drawing-assisted path provided. A separate bounded crown-support fit must therefore detect upright circular supports and horizontal platform outlines directly from the cloud. Pipe candidates require multi-height circular support, observed endpoints and bounded radius/lean/residual. Platform candidates require a connected broad footprint around the shaft; unresolved thickness is inferred. Device parent links require a unique measured support with compatible back-plane and vertical overlap. Missing or ambiguous supports remain explicit gaps; no baseline counts or geometry may fill them.

Original-photo classification may refine the identity of an unknown enclosure while preserving its measured pose. Generated cloud crops are scan evidence, not original photographs. Only a classified device with a measured parent may receive conventional inferred clamps or cable geometry. Attachment locations and routes remain inferred even when the device centre is measured. These measurement changes invalidate earlier evidence through component algorithm version 6.

Benchmark inputs are source clouds and original photos only, with no drawings, saved proposal, previous GLB or external camera-pose file. Source layer metadata and their effective offsets are retained. Evaluation compares device counts, matched centres/dimensions/bearings, missing/extra candidates, model bounds and coordinate frame against the frozen baseline; it also checks against the cloud itself. Reference disagreement is not automatically a detection error because the reference includes inferred and drawing-supported values.

All real data and runtime artifacts remain in an ignored directory in the current worktree. No main edits, merge, rebase, push, shared profile use or Playwright E2E. UI Fix is notified through the existing coordination channel and controls integration. New cloud AI use follows the existing one-input-pool/one-budget approval policy; local preparation and testing proceed first.

Acceptance: a fresh drawing-free run creates a valid GLB with separate equipment nodes, retains cloud placement/scale/orientation, reports unsupported or missing details, and produces honest side-by-side and overlay visual evidence. Synthetic tests cover input ordering, rigid frame changes, sparse/partial equipment and duplicate rejection. A measured improvement is required; exact parity must not be claimed when the comparison does not support it.
