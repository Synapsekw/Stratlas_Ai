# App 0.22.0 and pipeline pack 0.17.0 version bump

## What changed

- **App version:** 0.21.0 to 0.22.0 in `apps/desktop/package.json`, the online tiles user-agent comment, `TESTING.md` and NORTH-STAR section 3.
- **Pack version:** 0.16.0 to 0.17.0 in `python/pyproject.toml` and `uv.lock`.
  - The pano stitch quality, line-up turn and scale, and walk-frame work changed the Python pipelines since pack 0.16.0.
- **Pack app range:** `APP_RANGE` is now `>=0.22.0 <2.0.0`, so an app before 0.22 refuses pack 0.17.0 with its existing message.
  - Pack 0.17.0 writes line-up turns (`captures[].lineUpTurn`). An older app would drop them and show the date shift-only, so the dates would be quietly misplaced. This closes the review minor on #189.
- **Settings guide:** says that the line-up turn and the improved panorama stitching come with pack 0.17.0, which needs app 0.22.0 or later.
- **Feature gates:** no `*_MIN_PACK` changes. Every feature keeps working on the pack it needed before; the newer pack only improves results.
- **Landing:** this bump rides a merge train with #184 (measurement layers). The installer is built from the train head.

## Why

Every handed-over build gets a new version (handover section 4).

Since 0.21.0, these landed:

- #181 Create maps from photos under the project name.
- Train 2:
  - #182 drone panorama stitch quality;
  - #183 antenna review.
- Train 3:
  - #185 local detection on 360 video;
  - #189 Line up dates with a turn and a scale.
- #188 RF coverage simplified.
- With this bump: #184 measurement layers.

## How to test

1. Install `QuadrionAI-0.22.0-win-x64-setup.exe` from `apps/desktop/dist` over 0.21.0. Settings > About and updates shows 0.22.0 and this build's commit.
2. In Settings > Processing tools, install `pipeline-pack-0.17.0-win-x64.tar.gz`. An app 0.21.0 refuses this pack with a "needs a newer app" message.
3. Follow the How to test steps in the related session notes.
