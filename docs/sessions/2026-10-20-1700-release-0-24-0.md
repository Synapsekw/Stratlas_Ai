# Release 0.24.0 (app) and 0.19.0 (pipeline pack)

## What changed

- The app goes to 0.24.0 and the pipeline pack to 0.19.0. This bump is the last commit of the build train `train/2026-10-20-2`.
- The train carries, in this order:
  - #206 (sessions README names the north-star check hook);
  - #203 (ODM first-start check: cancel, quit mid-check is a cancel, an unverified previous install is tracked);
  - #204 (docs follow-ups: PRD v1.2 approved, the contract sign-off dropped, the photo guide renumbered to 46, a `packages/rf` README);

- `APP_RANGE` stays `>=0.22.0 <2.0.0`. Pack 0.19.0's live progress fields are optional, so an older app ignores them, and app 0.24.0 with an older pack shows no live line.
- Release notes: `tools/release/previous-release.json` now names `c8131db5`, the commit 0.23.0 was built from. The 0.24.0 notes cover the commits since then.
- The founder asked that this build include all of #203, #204 and #205.
