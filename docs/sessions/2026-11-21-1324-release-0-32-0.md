# Release 0.32.0 (app), pipeline pack 0.35.0 and Analytics pack 0.2.0 unchanged

## What changed

- The app goes to 0.32.0 in this PR (`119615d8c`): `apps/desktop/package.json`, the installer name in `docs/TESTING.md`, the phase line of `docs/NORTH-STAR.md`.
- `tools/release/previous-release.json` now names `b54441b0e`, the commit 0.31.0 was built from, so the 0.32.0 release notes cover the commits since then.
- Neither pack is rebuilt. Nothing under `python/` or `tools/pipeline-pack` changed since 0.31.0, so the build reuses `pipeline-pack-0.35.0-win-x64.tar.gz` and `analytics-pack-0.2.0-win-x64.tar.gz` as they are; both archives still have the SHA-256 recorded for 0.31.0. `docs/guide/12-settings.md` and `docs/KNOWN-LIMITS.md` need no change.
- The build carries everything on local `main` since 0.31.0: volumetrics finalized, the fixes from the two volumetrics test rounds, the rebuilt volumetric report, tools shown by project type, and the space an Inspector import filled shown on screen.

## Why

The founder asked for a new installer of the open local batch, to test the rebuilt volumetric report and the rest of the volumetrics section in the packaged app.

## How to test

Nothing is user-facing in this PR beyond the version number. With the 0.32.0 build:

1. Run `QuadrionAI-0.32.0-win-x64-setup.exe` from `apps/desktop/dist` and install over 0.31.0.
2. Open Settings, About and updates: it shows 0.32.0 and lists the changes since 0.31.0.
3. Open Settings, Processing tools: it still shows Version 0.35.0. The pack does not need to be installed again.
