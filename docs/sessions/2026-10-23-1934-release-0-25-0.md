# Release 0.25.0 (app), pipeline pack 0.24.0

## What changed

- The app goes to 0.25.0 in this PR: `apps/desktop/package.json`, the user agent example in `onlineTiles.ts`, the installer name in `docs/TESTING.md`.
- The pipeline pack stays at 0.24.0. Antenna manual flagging set it (`b1e5ef0f`), nothing under `python/` has changed since, and no 0.24.0 pack has been built or handed over yet, so the 0.25.0 build is its first. It is built fresh from the bump commit and so carries pillow 13.0 and certifi 2026.10.19 (`9d9b3e63`), the pickle fix for volumetric pile data (`f83239f8`) and the CSV formula guard of the pipeline writers (`292b22a3`), all on `main` before the pack bump. `APP_RANGE` stays `>=0.22.0 <2.0.0`.
- `docs/guide/12-settings.md` lists what packs 0.21.0 to 0.24.0 bring (photo corrections, thermal, local detectors, antenna flagging). `docs/KNOWN-LIMITS.md` names no app version, so it needs no change.
- Release notes: `tools/release/previous-release.json` now names `ecd64c79`, the commit 0.24.0 was built from. The 0.25.0 notes cover the commits since then.
- `docs/release/README.md` (founder, 23 Oct 2026): every handed-over build also rebuilds the Store `.msix` (`dist:win:store`) in the same version as the setup exe; the Analytics pack is handed over beside the installer and inside the team kit zip, which is then over 4 GiB and must be written as ZIP64 (bsdtar `tar.exe -a -cf` or 7-Zip, not `Compress-Archive`).
- conda ca-certificates is not re-locked. conda-forge has 2026.10.19, but the repository's own relock (`pdal.mjs --lock`, `ffmpeg.mjs --lock`) re-solves the whole environment: for ffmpeg on win-64 it pulled in a Python 3.15, glib and pango development packages. That needs a pack build to check, and the Windows pack copies only the programs, their DLLs and the PROJ and GDAL data (`keepWindows`), so the conda CA bundle never reaches it. The item is dropped from the north star.

## How to test

Nothing is user-facing in this PR beyond the version number. With the 0.25.0 build:

1. Install `QuadrionAI-0.25.0-win-x64-setup.exe` over 0.24.0, then `pipeline-pack-0.24.0-win-x64.tar.gz` in Settings, Processing tools; the page shows Version 0.24.0.
2. Settings, About and updates shows 0.25.0 and lists the changes since 0.24.0.
