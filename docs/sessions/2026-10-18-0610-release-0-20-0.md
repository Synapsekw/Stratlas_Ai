# App 0.20.0 version bump

## What changed

- The app version goes from 0.19.0 to 0.20.0 in `apps/desktop/package.json`, the online tiles user-agent comment, `TESTING.md` and NORTH-STAR section 3.
- The processing pack stays at 0.15.0. The RF backend (#169) already bumped it, and nothing under `python/` changed after that.
- Settings guide: the processing tools paragraph now says detecting antennas needs pack 0.14.0 or later, which `telecomPack.ts` already enforces.
- `pinned-media.spec.ts` "a 360 with no GPS is pinned": `scenePoint` now also waits for the camera pose to hold still for three frames. On this branch the test failed twice on CI with the click 7 m off; it passed on main and 3 of 3 times locally the CI way after the fix.

## Why

Every installer handed over gets a new version, and the bump lands green on its own before the build (handover section 4). This build is the founder's overnight request after UI rework stages 2 and 3 (#173), the telecom antenna UI (#174) and the RF coverage UI (#175).

## How to test

1. Install `QuadrionAI-0.20.0-win-x64-setup.exe` from `apps/desktop/dist` over 0.19.0.
2. Settings > About and updates shows 0.20.0 and this build's commit.
3. Settings > Processing tools: install `pipeline-pack-0.15.0-win-x64.tar.gz` from the same folder.
4. Then follow the How to test steps in the three session notes listed above.
