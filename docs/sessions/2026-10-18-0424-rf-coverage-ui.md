# RF coverage UI

## What changed

- This PR lands T8 to T12 of the RF coverage plan on top of the backend (#169) and stages 2 and 3 (#173): the RF store, the RF workbench tab with the catalogue picker and CSV import, the coverage layer on the map and in 3D with a live preview Worker, the Display bench Coverage group, the "Coverage..." project action and an e2e test that runs the real Python job.
- The legend takes a bottom corner through one marked block in `Stage.tsx`, the one away from the 3D readout (also right to left and in a split). It is compact, with the controls behind Details.
- A run larger than 2048 cells on its long side is read and reduced in a Worker, so at most 2048 x 2048 cells are drawn; class areas are counted on the full grid there and exports stay full size. The tab and Details say when the view is reduced.
- Starting a run opens the RF tab but is not a live tool: the drawer, panels and agent pane stay as they are, the Jobs tab shows the run, and closing the RF tab does not cancel it.
- Main refuses `rf.coverage` on a pack older than `RF_COVERAGE_MIN_PACK`; the live preview is skipped past 2048 x 2048 pixels and the run is still allowed.

## Why

The founder wants coverage predicted from the measured antenna azimuth and tilt, with antenna, radio and AAU selection. Phase 1's engine landed without UI; this PR puts it in front of the person.

## How to test

1. Open a project with `telecom/antennas.json`. Right-click the project heading, choose Coverage...; the RF tab opens.
2. Group by bearing, pick sector S1 and an antenna, band n78 at 100 MHz, then the generic n78 AAU. Power reads "AAU total power".
3. Do the other sectors, click Run coverage. The agent pane stays open; when the job ends the class table fills and coverage shows with the legend at a bottom corner.
4. Move one electrical tilt: the class table and map update live. In Display, under Coverage, toggle the eye, drag Opacity, try Export, GeoTIFF.
