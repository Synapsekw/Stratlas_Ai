# RF coverage UI

## What changed

- This PR lands T8 to T12 of the RF coverage plan on top of the backend (#169) and stages 2 and 3 (#173). It adds an RF store (heights, sectors, orphans, run refusals), the RF workbench tab with the catalogue picker and CSV import, the coverage layer on the map and in 3D with a live preview Worker, the Coverage group in the Display bench, the "Coverage…" project action and an e2e test.
- The legend takes a bottom corner through one marked block in `Stage.tsx` (coordinator ruling). It is compact by default, with opacity, Show from, hatch and assumptions behind Details. It prefers bottom left so the 3D readout stays visible.
- Main refuses `rf.coverage` on a pack older than `RF_COVERAGE_MIN_PACK`, and the built-in catalogue now loads in an unpackaged launch.
- The live preview is capped at 2048 x 2048 pixels; above that it is skipped with a reason and the run is still allowed.
- The e2e test runs the real Python job, from Coverage… through to reopening the project. The test found, and this PR fixes, unsaved RF edits being dropped when another tab came to the front.

## Why

The founder wants coverage predicted from the measured antenna azimuth and tilt, with antenna, radio and AAU selection. Phase 1's engine landed without UI; this PR puts it in front of the person.

## How to test

1. Open a project that has `telecom/antennas.json` (run antenna detection first). Right-click the project heading and choose Coverage…; the RF tab opens.
2. Click Group by bearing, pick sector S1, then an antenna. Choose band n78 at 100 MHz, then choose an AAU (for example the generic n78 AAU). The antenna and radio fields grey out, and power reads "AAU total power".
3. Repeat for the other sectors, then click Run coverage. When the job finishes, the class table fills in and coverage shows on the map and in 3D, with the legend bottom left.
4. Move one antenna's electrical tilt. The class table and the map update live, and Save as new run becomes available.
5. In Display, under Coverage, turn the eye off and on and drag Opacity. Then try Export, GeoTIFF.
