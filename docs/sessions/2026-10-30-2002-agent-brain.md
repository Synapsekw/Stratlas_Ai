# Agent brain: remembers its tool work, thinks, caches, runs longer

## What changed

- This PR makes the in-app agent remember what its tools returned. Each saved step keeps a compacted result (about 2 KB of JSON: images removed, long lists shortened, ids, names, positions and numbers kept), and every message sends the earlier tool calls and results back with the text. Follow-ups such as "fly to the second one" now use the ids from the turn before. Conversations saved by older builds still open: their steps are read back with the step summary as the result.
- Cloud runs think before they act (AI SDK `reasoning: medium`: adaptive thinking on Claude 5.x, reasoning effort on OpenAI and Google) and use Anthropic prompt caching (breakpoints on the system prompt plus tools, the end of the older history, and the newest message of each step). One switch turns both off: Settings, AI providers, "Agent thinking and prompt caching", below Model routing. On by default (founder decision).
- Cloud runs get 20 steps (was 8; the compact profile for small local models stays at 6). At the cap the agent writes one closing answer without tools: what it did, the figures, what is left.
- The full prompt gains a "How to work" section: plan, gather with read tools, act, read back to check, give numbers with units and their source.
- The agent is offered only the tools the project can use: no change tools with one survey date, no clip or photo tools without clips or photos, no modelling tools without a model (the Model builder's route keeps them).
- Contract change: `ChatMessage` (tool calls and a `tool` role), `ai:send.facts`, `ConversationStep.result`, `Settings.agentThinking`; row in `contract-changes.md`.

## Why

The intelligence review (study items 4.1, 4.2, 4.3 and 4.6) found that the agent forgot every tool result after each turn, never thought or cached, stopped cold after 8 steps and carried about 15 modelling tools in projects without a model.

## How to test

1. Settings, AI providers: below Model routing, "Agent thinking and prompt caching" is on.
2. Open a project with tagged assets, open the agent and ask "Which tanks are there?". After the answer, ask "Fly to the second one": the camera flies to the second tank of the list without the agent searching again.
3. Close the app, open it again, resume that conversation from the history list and ask "and the first one?": it still knows the list.
4. Ask a long task ("compare every survey date and draft an issue for the biggest change"): on a cloud model it can take up to 20 steps; if it runs out it ends with a short summary of what is done and what is left, not "Send another message".
5. In a project with one survey date ask "compare the captures": no change tool is called (none is offered); the agent explains there is only one date.
6. Turn the switch off and ask again: replies come without the thinking pause; usage in Settings, Usage shows no cache reads.
