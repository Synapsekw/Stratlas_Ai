# Release 0.23.0 (app) and 0.18.0 (pipeline pack)

## What changed

- The app goes to 0.23.0 and the pipeline pack to 0.18.0, as the last commit of the build train `train/2026-10-20-1`.
- The train carries #199 (release notes), #200 (Stop hook without drafts), #198 (ODM install check), #194 (measurement filter) and #201 (area-scoped change detection), in that order.
- `APP_RANGE` stays `>=0.22.0 <2.0.0`. Pack 0.18.0 adds area-scoped change jobs with optional params that an older app never sends, so app 0.22.0 can still use it. App 0.23.0 with pack 0.17.0 refuses an area run with "needs newer processing tools" (#201).
- Release notes: `tools/release/previous-release.json` names `3c8634a1`, the commit 0.22.0 was built from. With no `v*` tags, the 0.23.0 notes cover the commits since that build. The next bump sets the file to the commit 0.23.0 is built from.
- The guide's processing tools section names pack 0.18.0 for area comparison. TESTING points at the 0.23.0 installer.

## Train notes

- `docs/NORTH-STAR.md` and `docs/architecture/contract-changes.md` conflicted for #198, #194 and #201 after the docs refresh re-padded the table. They were resolved by keeping main's text and applying each PR's own lines and rows.
- Review rounds before the train: #194 needed two rounds (load and write races, then a selection ref that wasn't pruned on delete), and #201 needed one (polygon frame on a lined-up date, a 0.22 write-back, look-only menu, an area outside the data, an unknown CRS, and reruns). #198 landed with two follow-ups owed: keep the old ODM folder until an update passes its check, and cancel or kill the first-start check on quit and write the record first (`fix/odm-check-cancel`).

## How to test

1. Install `QuadrionAI-0.23.0-win-x64-setup.exe` over 0.22.0, then pack `pipeline-pack-0.18.0-win-x64.tar.gz` in Settings, Processing tools.
2. Settings, About and updates lists this version's changes, not "Release notes are not available".
3. Follow the How to test steps in the session notes listed above.
