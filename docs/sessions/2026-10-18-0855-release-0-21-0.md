# App 0.21.0 version bump

## What changed

- The app goes from 0.20.0 to 0.21.0 in `apps/desktop/package.json`, the online tiles user-agent comment, `TESTING.md` and NORTH-STAR section 3. The pipeline pack is 0.16.0, bumped by engineering fidelity (#179).
- The settings guide now lists the pack each tool needs: RF coverage needs 0.15.0, and a new engineering component model needs 0.16.0.
- NORTH-STAR section 3:
  - Phase, Branch and In flight were rewritten after the four landings since 0.20.0 (#176 to #179).
  - The engineering review follow-ups were added.
  - Two known flaky e2e were recorded: `panels.spec.ts:617` and `globe.spec.ts:1012`.

## Why

0.20.0 was built before RF follow-ups (#178), telecom and pinned follow-ups (#177) and engineering fidelity (#179) landed. Every handed-over build gets a new version, and the bump lands green on its own before the build (handover section 4).

## How to test

1. Install `QuadrionAI-0.21.0-win-x64-setup.exe` from `apps/desktop/dist` over 0.20.0.
2. Settings > About and updates shows 0.21.0 and this build's commit.
3. In Settings > Processing tools, install `pipeline-pack-0.16.0-win-x64.tar.gz`.
4. Engineering: create a new component model on an engineered asset. When the run finishes, the Model review tab opens in the right sidebar without closing other panels. Then follow `sessions/2026-10-18-0745-engineering-review-workbench.md`.
5. Follow the steps in the follow-up notes listed above, then the 0.20.0 notes.
