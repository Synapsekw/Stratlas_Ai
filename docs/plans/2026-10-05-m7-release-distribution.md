# Next phase: M7 Release hardening and distribution

> Draft, 5 Oct 2026. Starts when CI on `main` is green. Test steps go into stage M7 of `docs/TESTING.md`.

**Goal:** a Stratlas customers can install and keep up to date on Windows and macOS: signed builds, a Microsoft Store listing with a demo project, offline-capable updates, a diagnostics bundle for support, accessibility and performance across ordinary hardware, and a user guide.

## Global constraints

- Offline first: nothing in the app calls out unless the user starts it (map downloads, updates check, cloud AI).
- Never ship client data: the demo project is built from data Synapse Solutions may publish (synthetic or own captures), checked by a script before every Store build.
- Signing secrets only in GitHub Actions secrets or the founder's machine, never in the repo or chat.
- Test windows stay off-screen (`STRATLAS_USER_DATA`), e2e `--workers=1` locally; CI green on Windows and macOS before every merge.
- Version from 0.1.0 to 0.7.0 at the start of M7 (one minor per milestone), so installers and update feeds are distinguishable.

## Review focus

- An update interrupted (power, network, app quit) never leaves an install that will not start; the previous version stays runnable.
- A first start on a clean machine with no data root, no packs, no pipeline pack and no network explains each missing piece and still opens the demo project.
- macOS: Gatekeeper accepts the notarised app; file associations (`.aio`) and the custom protocol work; Apple silicon and Intel.
- Low-end GPU (integrated graphics, 8 GB RAM): the Low tier opens every project without crashing; the app picks it automatically.
- Screen reader and keyboard only: every screen is reachable and announced; focus never lost in popovers.

## Streams

| Stream                              | Scope                                                                                                                                                                                                                                                                    |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| D1 Version and updates              | Version 0.7.0; release notes from conventional commits; update check against a feed (optional, off by default) and offline update from an installer file; differential download; rollback to the previous version if a new one fails its first start                     |
| D2 Windows signing and Store        | Azure Trusted Signing (or certificate) wired in CI with secrets; signed NSIS and portable; MSIX/AppX rebuilt with the Store identity; Store listing assets (screenshots, description, privacy policy text); a submission checklist the founder runs                      |
| D3 Demo project                     | A publishable demo (synthetic or Synapse-owned data) showing fusion (model + video + map + point cloud), annotation, volumes and a road stretch; bundled in the installer and the Store build; first-start welcome opens it; scripted check that no client data is in it |
| D4 macOS                            | Universal build (arm64 + x64), Developer ID signing and notarisation in CI, DMG + zip, `.aio` association, menu and shortcuts per macOS conventions, Keychain for API keys, pipeline pack for macOS                                                                      |
| D5 Diagnostics and support          | Export a diagnostics bundle (logs, versions, GPU, settings without secrets, last errors), a crash handler that writes a report locally, a "Report a problem" flow that saves the bundle (no upload)                                                                      |
| D6 Accessibility and keyboard       | Audit with axe in e2e on every screen, focus management, ARIA for the stage tools and popovers, high-contrast and reduced-motion, keyboard map in Settings                                                                                                               |
| D7 Performance on ordinary hardware | Tier detection on integrated GPUs, memory caps for point clouds and rasters, perf budgets per tier in CI on a recorded path, startup time budget                                                                                                                         |
| D8 User guide                       | In-app help (offline, searchable) and a PDF user guide: install, projects, scene, annotation, maps, AI, building projects, reports, packages; screenshots generated by e2e                                                                                               |
| D9 Stability                        | Flaky tests fixed (agent.spec workspace ID), `tools/pipeline-pack/build.mjs` cleans up after a failed build, nightly installers green                                                                                                                                    |

## Exit

- Signed Windows installer and a Store submission package ready for the founder; notarised macOS DMG from CI.
- A clean Windows and a clean macOS machine install, open the demo project, update to a newer build and roll back.
- Stage M7 of `docs/TESTING.md` complete.
